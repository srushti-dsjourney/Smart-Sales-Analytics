# 📊 Smart Sales Analytics

### Sales Analytics & Forecasting Dashboard

**Smart Sales Analytics** is a web-based sales analytics platform built with Python and Flask. It transforms raw sales data into actionable business insights through interactive dashboards, customer analytics, product performance analysis, and machine-learning-based sales forecasting.

## 🎯 Project Objective

The goal of this project is to help businesses understand sales performance, customer behavior, product performance, and future sales trends using data analytics and machine learning.

## 🚀 Key Features

### 📈 Sales Analytics

* Total Revenue
* Total Orders
* Total Customers
* Average Order Value
* Monthly Sales Trends
* Category-wise Sales
* City-wise Sales
* Top-performing Products

### 👥 Customer Analytics

* Customer Spending Analysis
* Repeat vs One-time Customers
* Top Customers
* Average Customer Spending
* Customer Segmentation

Customers are categorized into:

* High Value
* Regular
* Low Value

### 📦 Product Insights

* Best-selling Products
* Lowest-performing Products
* Product-wise Sales
* Product Performance Comparison

### 🔮 Sales Forecasting

The project uses **Linear Regression** to predict future monthly sales based on historical sales trends.

The forecasting module provides:

* Predicted Sales
* Forecast Month
* Mean Absolute Error (MAE)
* R² Score

### 🔍 Interactive Dashboard Filters

Users can analyze specific parts of the dataset using:

* City
* Product
* Payment Mode
* Start Date
* End Date

Dashboard metrics and visualizations update based on the selected filters.
